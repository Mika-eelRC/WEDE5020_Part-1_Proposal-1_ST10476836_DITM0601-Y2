## Project Overview
This project focuses on designing and developing a responsive, multi-page website for the **Foundation for Community Work (FCW)**, a non-profit organisation based in the Western Cape, South Africa. FCW is dedicated to promoting Early Childhood Development (ECD) and empowering under-resourced communities through home-based educational support, caregiver training, and resource distribution. 

The website aims to bridge the gap between FCW, local families needing ECD services, and donors or partners looking to support community development initiatives.

---

## Website Goals and Objectives
* **Promote Early Childhood Development:** Raise awareness about FCW's early education programs and family intervention services.
* **Streamline Community Access:** Provide caregivers and fieldworkers with accessible information regarding learning resources and training opportunities.
* **Facilitate Donations & Support:** Create a direct, clear pathway for corporate sponsors and donors to contribute to community projects.
* **Ensure Digital Accessibility:** Build a lightweight, responsive interface optimized for desktop, tablet, and mobile devices across low-bandwidth environments.

---

## Key Features and Functionality
* **Semantic 5-Page Architecture:** Fully structured HTML5 layout separating core site sections cleanly.
* **Responsive Layout (Planned for Part 2):** Mobile-first and desktop-friendly responsive styling using modern CSS layout techniques.
* **Interactive Contact & Inquiry Form:** Enables community members and partners to send messages directly with client-side validation.
* **Embedded Media & Services:** Integration of interactive Google Maps for physical location and embedded video content highlighting community impact.
* **Donation System:** Interactive donation tier display paired with clear direct banking (EFT) guidelines for transparent contributions.

## Part 1 Details
This current submission represents **Part 1: Building the Foundation**.
* **File Structure:** Organised directory separating `css/`, `js/`, and `images/` from core root HTML documents.
* **Semantic HTML Structure:** Developed complete HTML skeletons for all 5 required pages (`index.html`, `about.html`, `services.html`, `contact.html`, and `donate.html`) utilizing standard HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
* **Content Gathering:** Collected logo and local media assets sourced from official FCW public platforms and placed them within the `images/` directory.

> *Note: Visual design, CSS styling (Part 2), dynamic interactive scripts, and final SEO optimizations (Part 3) will follow in upcoming submissions.*
